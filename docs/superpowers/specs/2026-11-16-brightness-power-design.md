## 目标与范围

在现有控制页增加所选屏幕亮度、逐屏亮度详情、系统电源模式、现有电源计划、电池／交流供电状态及 Windows 电源设置入口。沿用现有唤出、主题、面板尺寸与声音功能；不另建应用副本。

首版不包括多屏同步、软件遮罩调暗、自动亮度、定时切换、关机重启、CPU 超频、功耗限制、风扇及厂商专用性能模式适配。

## 方案选择

1. 完整兼容方案（用户已选择）：内置屏使用 Windows WMI 亮度能力，外接屏使用 Windows DDC/CI 监视器配置接口；电源使用公开 Win32 接口。检测实际能力并分别呈现错误。
2. 简化方案：仅内置屏与系统电源，较快但台式机可能没有可用亮度控制。因希望其他电脑也能使用，未选择。

## 交互与保存

- 控制主页面：增加所选屏幕名称、亮度百分比滑块、显示器详情入口、电源模式快捷选择及供电状态。详细项目进入内部详情，不放入设置菜单，不扩大默认面板。
- 显示器详情：逐屏显示名称、主屏标记、支持状态及亮度；不支持或无法读取的项目禁用，显示原因，不显示假的 0%。提供刷新。
- 电源详情：分开呈现系统电源模式和已有电源计划，保留厂商、自定义计划名称及 GUID，不创建、删除或修改计划内容。电池缺失／未知与正常交流供电分别呈现。
- 电源模式只修改用户当前供电状态对应的 AC 或 DC 配置；供电状态在提交前改变时拒绝旧请求并刷新。读取用户选择，能读取有效模式时分开展示，避免把用户偏好当成一定生效。
- Windows 设置入口使用 `ms-settings:powersleep`；失败时提示，不影响其他控制。
- 文件坞仅保存偏好的屏幕稳定标识；设备断开后保留偏好并只更新可见读数。亮度、模式、计划由设备／Windows 管理，启动与返回页面不重放写入。偏好保存失败时反馈并保留原保存值。

## 硬件、线程与生命周期

- 亮度和电源分别使用独立、按需启动的单工作队列，沿用声音控制器的代际检查思路，不改造无关音频代码。声音不等待显示器驱动调用。
- 每个请求绑定屏幕稳定标识与当前连接代际；拔出、重连或枚举失败时不得将旧写入转给其他屏幕。无法可靠区分的物理目标禁用写入。
- WMI 只枚举活动亮度实例，通过设备标识映射到屏幕；DDC/CI 检查能力、最小／最大／当前值。物理亮度按设备范围归一化到 0～100%，不假定原始范围就是 0～100。
- 滑块合并短时间连续请求，松手立即提交；写入后读回，失败回到实际读数。禁止初始化绑定触发写入。
- 页面显示时才订阅相关系统事件；重新显示、显示拓扑改变、供电变化或手动刷新时按需读取。首版不轮询外接屏按钮操作，手动刷新或重新展开可更新。
- 收起、切页、锁屏、睡眠时取消待提交操作、停止订阅并使旧结果失效。已经进入驱动的调用无法保证中断：保持单个在途任务，不无限创建替代线程；UI 不等待，返回后释放资源。
- 原生句柄和 WMI 对象都在成功、失败及停止路径释放；暂停期间不发新硬件查询。不新增常驻 PowerShell、驱动、Windows 服务或第三方控制程序。
