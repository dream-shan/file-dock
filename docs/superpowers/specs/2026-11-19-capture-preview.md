# 区域截图与坞内预览

两个独立动作共用现有工具页、文件页和快捷键管理。用户可只通过鼠标使用，初始键位均为空。截图绑定的作用域是 Windows 桌面，预览绑定的作用域是文件坞中有焦点的文件行。选择作用域的依据是截图可从任何应用发起，而预览需要一个明确的文件目标。

## 截图

工具页紧凑行左侧开始框选，右侧设置是否包含文件坞并进入快捷键编辑。按需取得单帧桌面图像，在框选结束后复制、保存 PNG 或取消。默认临时隐藏文件坞的面板、标签和边缘入口。成功、取消和失败均恢复进入时的显示状态。原有的系统截图协作独立处理。

## 预览

常用文件、文件夹内容与搜索结果共用右键预览。图片使用已有解码逻辑，PDF 按页渲染，文本按上限读取。切换文件或关闭窗口时取消旧请求。未知格式给出文件信息和默认应用入口。资源管理器集成另行评估。

第二阶段在打开时记录当前文件列表的顺序，允许在一个窗口连续浏览。关闭时，原列表和查询仍匹配且最后浏览的文件仍可见时恢复行焦点。新增操作提供鼠标按钮，沿用统一快捷键的默认空键位规则。

PDF 可输入页码定位并复用已打开的文档。图片按需切换至原始像素，原图解码以 3,200 万像素为上限。文本只查找已经载入的字符。Markdown 用本地解析库生成 WPF 阅读视图，外部链接和图片以文字呈现，可切换回文本原文。

## 验收

检查反向和跨屏选区、PNG 内容、取消与面板恢复。覆盖图片、PDF 翻页、中文文本、损坏文件、快速切换及文件释放。验证首次启动与旧配置升级、局部空格键、全局快捷键冲突，以及录入时的动作抑制。
