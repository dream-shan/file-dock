# 软件内部快捷键目录

第五阶段的首批交付是手动登记和 VS Code 只读来源。从统一快捷键管理进入，按所选软件展示条目。软件可来自固定应用、指定程序路径或当前选中的窗口。

手动条目保存动作名、原键、用户标注的范围和可选备注。目录按所选入口路径保存，程序与快捷方式在选择列表中分别标明。VS Code 条目以来源文件为单位保存，区分用户配置和用户另存的默认键位。保留原顺序、命令标识、按键文本、上下文和全局声明。带参数的条目记录存在参数，具体参数保留在来源文件中。空命令、移除规则也是配置的一部分。一个来源刷新失败时保留上次成功读取的记录。

所有记录用现有保存机制储存在文件坞的 Data 中。界面明确展示配置来源，VS Code 自己处理的动态上下文和扩展覆盖情况以其键盘快捷键编辑器为准。

5.3 按前台应用映射和 5.4 原生修改是后续工作。本轮验证软件目录记录与已注册快捷键互相独立，以及配置保存、JSONC 读取和源文件保护。
