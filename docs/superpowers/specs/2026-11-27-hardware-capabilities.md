# 控制中心：硬件识别与能力探测（6.1）

## 目标与边界

6.1 在控制中心新增「硬件与性能」卡片与内部详情页，按需识别当前电脑硬件并客观展示受支持的性能参数能力，为 6.2（本机提权服务受控调节与方案保存）建立统一模型。

- 主程序保持普通权限，本阶段仅只读识别，不修改任何硬件参数，不新增后台轮询或常驻服务。
- 硬件通道使用独立的懒加载 `ControlWorkQueue`，与音频、亮度、电源、无线相互隔离；控制页收起、切页或暂停时停止活跃，静态硬件档案与厂商类探测在同次运行内缓存，手动刷新仅更新实时 GPU 遥测。

## 识别与能力矩阵

- **硬件档案**：通过 `root\cimv2` 读取机型、形态（笔记本 / 台式机）、主板与 BIOS、CPU 与物理显卡，自动过滤常见虚拟显示适配器。
- **NVIDIA NVML 遥测**：通过系统 `nvml.dll` 只读获取实时功耗、生效上限、默认及硬件范围、核心/显存频率、温度、风扇（桌面卡）与性能状态；缺失驱动或可选导出时优雅降级。
- **厂商 WMI 接口识别**：在 `root\wmi` 按白名单只读检测常见品牌硬件控制类定义（Lenovo Legion WMI、ASUS ATK WMI、HP OMEN WMI、Dell/Alienware WMI、MSI ACPI WMI），不扫描无关类、不调用写入方法。
- **四项能力状态**：对「厂商性能模式」「功耗控制」「风扇转速与曲线」「频率与超频」分别输出 `只读可用`、`需提权服务`、`本机不支持` 或 `暂不可读` 及具体依据。

## 下一阶段（6.2 规划）

6.2 沿用「主程序普通权限 + 本地提权服务」边界：由独立服务在读取厂商 BIOS 安全上下限（如 `LENOVO_CAPABILITY_DATA_00/01`、`LENOVO_FAN_TABLE_DATA`）后校验并应用性能模式、功耗墙、自定义风扇曲线或超频偏移，同时支持用户方案保存与一键恢复默认。
