文件坞 Demo 0.7.1 · Windows x64

启动：双击 FileDockDemo.exe。程序已包含运行时，无需另装 .NET。

使用：
- 点击“我的常用”旁的“＋ 添加”选择常用文件或文件夹。
- 单击文件夹，在文件坞内显示内容；继续单击子文件夹可逐层进入。
- 单击文件，用系统默认应用打开；无需先到文件管理器中选择。
- 浏览时可点返回、上一级、我的常用，或点击路径中的任意上级文件夹。
- 进入文件夹后，输入关键词会自动搜索当前文件夹及所有子文件夹中的文件和文件夹名称。
- 不输入关键词或清空搜索时，只显示当前层列表。
- 递归结果会显示相对位置；类型筛选应用于搜索结果。最多显示 1000 项，达到上限时请增加关键词。
- 隐藏及系统项目、子目录链接内部不参与搜索；无法读取的子目录会跳过并提示，结果可能不全。
- 右键项目可固定到常用、复制路径或打开所在位置；文件夹右键可另选“在文件管理器中打开”。
- 拖动常用卡片调整顺序；常用页搜索框按名称或路径筛选。
- 顶部箭头收起到屏幕边缘；点击贴边入口再次展开。
- 贴边入口更小（20 × 48），平时半透明、悬停时变清晰；切换普通或无边框全屏窗口后仍可点击唤出。
- 首页改为电脑状态：CPU/GPU 占用及温度、内存、显存；小横栏显示实时上传/下载速率。
- 独占全屏游戏、安全桌面、其他 Windows 虚拟桌面不保证覆盖。
- 主面板和贴边入口不显示在 Alt + Tab 切换列表或任务栏；可通过贴边入口、托盘图标和快捷键唤出。
- Ctrl + Alt + Space 展开/收起，Ctrl + F 聚焦搜索，Esc 收起。
- 浏览时 Alt + ← 返回，Alt + ↑ 上一级，F5 刷新当前文件夹。
- 图钉开启后保持展开；设置菜单可切换贴边方向、开启开机启动。
- 右键托盘图标选择“退出”，可完全关闭程序。

首次运行会添加程序所在目录、桌面和文档三个入口，可自行移除。
配置保存在程序旁的 Data 文件夹；添加与移除入口均不搬动原文件。
首页展开时每 1 秒持续更新电脑状态；CPU 温度每 1 秒读取一次。收起或进入文件夹后暂停。趋势最多保留本次展开后的 60 个样本（约一分钟）。
已移除最近使用、相关后台监听和底部拖入区域，不再读取或记录文件访问历史。网速只统计实际物理网卡流量，不主动测速。

这是演示版：快捷键暂固定；多屏缩放切换及开机启动尚未进行实际环境切换验证。

源码：源码目录。修改后使用 .NET 10 SDK 运行其中的 Build.ps1，输出到“重建输出”目录。
程序自测：FileDockDemo.exe --self-test "一个新的测试目录绝对路径"
自测会在指定测试目录创建测试文件、配置、检查结果和界面截图。

技术：C# / .NET 10 / WPF。主程序保持普通权限；CPU 温度依赖官方签名 PawnIO 驱动和独立温度读取组件。


0.5.0 新增：
按住 Ctrl 点击文件可多选，松开 Ctrl 后拖动已选项一起复制，或 Ctrl+C 后到目标处 Ctrl+V。
拖出面板会自动收起，Esc 取消拖拽会恢复面板。
图片显示缩略图，悬停查看大图，右键可复制图片内容。
入口平时在本地和远程画面正常显示；使用本机 Snipaste 默认快捷键、PrintScreen 或 Win+Shift+S 截图时临时隐藏，结束后恢复。主动展开的面板可以截图。
网页是否接收拖放或粘贴，取决于网页本身；Snipaste 为重点兼容对象。

0.5.2 修复：取消入口持续的截图排除，避免远程桌面或投屏看不见入口。改为截图快捷键触发前隐藏、结束后恢复。自定义快捷键、其他截图工具及远程控制端截图不保证提前隐藏。


0.6.0：移除最近使用和底部拖入区域，新增电脑状态。CPU 温度由已安装的 FileDockTemperature 服务读取；服务无请求时不采样，主程序无需管理员权限。温度服务依赖 Windows 自带 .NET Framework 4.8 和官方签名 PawnIO 驱动。GPU/显存目前适配 NVIDIA。组件安装、构建及卸载见 README.md。

Release 下载包已包含 TemperatureService 子目录。首次使用 CPU 温度前需从 https://pawnio.eu/ 安装官方签名驱动，再在管理员 PowerShell 中进入解压目录，运行：.\TemperatureService\Install.ps1 -SourceDirectory .\TemperatureService。已安装的电脑无需每次重复安装。

0.6.1：修正 GPU 主占用率统计，改用 Windows 最繁忙引擎的占用率，包含计算、复制及视频编解码，并按显卡标识区分核显/独显。温度和显存继续由 NVIDIA 驱动读取。无法获取有效引擎数据时显示“—”；悬停 GPU 可查看统计来源及当前引擎。刷新改为每 0.5 秒连续更新，温度服务无需重复安装。不同软件采样窗口不同，读数可能短暂有差异。

0.6.2：电脑状态改为每 1 秒刷新一次；趋势保留 60 个样本（约一分钟），收起或浏览文件夹时仍暂停采集。

0.6.3：移除“包含子文件夹”选项，文件夹搜索始终包含当前目录及所有子目录；清空搜索恢复当前层浏览，保留类型筛选与相对位置。

0.6.4：程序、面板标题与托盘使用透明底的折角文件和停靠边标志。托盘根据 Windows 系统深浅主题切换浅色或深灰色；图标包含 16 至 256 像素的多尺寸资源。

0.7.0：默认跟随 Windows 应用主题，也可在设置 → 外观选择浅色或深色。切换立即生效并保存选择；托盘图标独立跟随 Windows 任务栏主题。菜单、文件夹、图片预览背景和侧边入口同步适配，图片原色不变。

0.7.1：CPU/GPU 卡片移除硬件型号，使用更高的趋势图、较粗折线和淡色填充；鼠标悬停图表可读出历史采样值。图表使用固定 0～100% 纵轴，保留最近 60 秒，每秒更新；收起暂停。小窗口自适应图表高度，内存/显存容量显示保留。
