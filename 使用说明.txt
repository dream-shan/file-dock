文件坞 Demo 0.3.1 · Windows x64

启动：双击 FileDockDemo.exe。程序已包含运行时，无需另装 .NET。

使用：
- 拖入文件/文件夹可固定；也可点“＋ 添加”选择。
- 单击文件夹，在文件坞内显示内容；继续单击子文件夹可逐层进入。
- 单击文件，用系统默认应用打开；无需先到文件管理器中选择。
- 浏览时可点返回、上一级、我的常用，或点击路径中的任意上级文件夹。
- 进入文件夹后，“包含子文件夹”默认开启；输入关键词会搜索当前文件夹及所有子文件夹中的名称。
- 取消勾选“包含子文件夹”即可只筛选当前这一层；清空关键词恢复当前层列表。
- 递归结果会显示相对位置；类型筛选应用于搜索结果。最多显示 1000 项，达到上限时请增加关键词。
- 隐藏及系统项目、子目录链接内部不参与搜索；无法读取的子目录会跳过并提示，结果可能不全。
- 右键项目可固定到常用、复制路径或打开所在位置；文件夹右键可另选“在文件管理器中打开”。
- 拖动常用卡片调整顺序；常用页搜索框按名称或路径筛选。
- 顶部箭头收起到屏幕边缘；点击贴边入口再次展开。
- 主面板和贴边入口不显示在 Alt + Tab 切换列表或任务栏；可通过贴边入口、托盘图标和快捷键唤出。
- Ctrl + Alt + Space 展开/收起，Ctrl + F 聚焦搜索，Esc 收起。
- 浏览时 Alt + ← 返回，Alt + ↑ 上一级，F5 刷新当前文件夹。
- 图钉开启后保持展开；设置菜单可切换贴边方向、开启开机启动。
- 右键托盘图标选择“退出”，可完全关闭程序。

首次运行会添加程序所在目录、桌面和文档三个入口，可自行移除。
配置保存在程序旁的 Data 文件夹；添加与移除入口均不搬动原文件。
最近使用合并 Windows 最近记录与本工具发起的打开记录。
系统记录的覆盖取决于应用和 Windows 设置，界面不把系统快捷方式时间当作精确打开时间。

这是演示版：快捷键暂固定；多屏缩放切换及开机启动尚未进行实际环境切换验证。
