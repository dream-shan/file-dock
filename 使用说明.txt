文件坞 File Dock · 0.8.0-rc.12 开源候选版
Windows x64 · 启动文件：FileDock.exe

首次使用
1. 将完整 ZIP 解压到自己有写入权限的目录，然后双击 FileDock.exe。
2. 无需另装 .NET，也不要以管理员身份运行主程序。
3. 点击“我的常用”旁的“＋ 添加”，选择文件或文件夹。
4. 顶部箭头收起，屏幕边缘入口或 Ctrl+Alt+Space 再次展开。
5. 设置菜单或托盘菜单中的“退出”完全关闭程序。
顶部 RC 表示候选版，鼠标悬停可查看版本。主题默认跟随系统，也可在设置中手动选择。

文件操作
- 单击文件夹在面板内浏览，单击文件由系统默认应用打开。
- 首页搜索常用项；文件夹内搜索当前目录及全部子目录中的名称，不是全盘搜索或文件内容搜索。
- 清空关键词恢复当前层。结果最多 1000 项；无法读取的目录会跳过并提示。
- Ctrl+单击多选，松开 Ctrl 后拖出整组文件，或 Ctrl+C 后到目标处 Ctrl+V。
- 图片显示缩略图，悬停看大图，右键可复制图片。网页需要自身支持拖放/粘贴，数量和格式由目标网页决定。
- 拖动单个常用卡片可排序。添加、移除入口不移动或删除原文件。
- Ctrl+F 搜索，Esc 收起，Alt+← 返回，Alt+↑ 上一级，F5 刷新文件夹。

电脑状态
首页展开时每 1 秒更新全部指标；收起或进入文件夹后每 2 秒只读取内存占用，CPU/GPU/温度/网速暂停；锁屏、会话断开或睡眠期间暂停。图表保留本次展开最近 60 个采样点。
CPU/GPU 占用、温度及容量读取失败时显示“—”，不代表 0。
GPU 温度、显存及显卡匹配目前适配 NVIDIA；其他厂商、同型号多卡尚不支持。
不同工具采样时间和窗口不同，读数不保证逐帧相同。
网速是当前物理网卡的实际上传/下载速率，不是宽带测速。
CPU 温度需另外安装官方 PawnIO 驱动和包内 TemperatureService 服务；文件功能无需这些组件。
先从 https://pawnio.eu/ 安装签名驱动，再以管理员身份打开 PowerShell，进入解压目录运行：
.\TemperatureService\Install.ps1 -SourceDirectory .\TemperatureService
已安装且正常工作的温度服务，本次无需重装。详细依赖、权限及卸载见 README.md。

升级与回退
先从菜单退出旧程序，并备份整个旧目录（尤其是 Data）。解压新版到原目录，保留原 Data。
从 FileDockDemo.exe 升级时，改用 FileDock.exe；旧 exe 移入备份，更新桌面/任务栏快捷方式。
新版首次正常启动会迁移指向同目录 FileDockDemo.exe 的旧开机启动项；不会自动开启原本关闭的开机启动。
自定义参数或另一目录的启动项保持原样。移动安装目录后，请重新设置开机启动和快捷方式。
回退前退出新版，用升级前整套备份恢复。不要只覆盖配置版本更高的新 Data。
配置仍在程序旁 Data 中。不要把个人 Data、备份或自测截图提交到公开仓库/问题反馈。

截图与兼容限制
入口通常在本地、远程桌面和投屏中可见；本机 Snipaste 默认 F1/Ctrl+F1、PrintScreen、Win+Shift+S 截图时临时隐藏，结束后恢复。
主动展开的主面板会进入截图；截图期间临时让出置顶和点击，结束或取消后恢复。其他截图工具、自定义快捷键、菜单启动截图和远程控制端截图不保证自动隐藏入口。
网页拖放、独占全屏、多屏缩放和不同硬件需按实际环境验证；无边框全屏与独占全屏不是同一种情况。
本候选版未作 Windows 代码签名；校验和仅核对完整性，不等同于签名。

卸载
先关闭开机启动，再退出程序。保留所需 Data 备份后移除程序目录，不会删除常用入口指向的原文件。
温度服务和 PawnIO 是独立组件，主程序退出/删除不自动卸载它们，具体步骤见 README.md。

本地诊断（0.8.0-rc.7）
Data\Diagnostics\current.jsonl 与 previous.jsonl 仅保存本机启动、退出、异常类型/方法、会话变化及界面状态，每 30 秒记录一次心跳。两份文件各不超过 512 KiB，自动轮换，不上传。不会记录文件名、路径、搜索文本或异常消息。
发现入口消失时，先不要重启程序，记下时间并尝试 Ctrl+Alt+Space；保留现场及这两份日志以便定位。日志未能写入或被强制终止时可能没有完整记录；本版只增加诊断，不宣称已修复退出问题。

0.8.0-rc.8 内存提醒与整理
内存圆环与百分比按占用青绿→黄→红连续渐变；入口从 65% 开始染色，超过 80% 为红色。偏高提示超过 80% 出现，低于 78% 消失。
点击内存卡片或 Tab 聚焦后按 Enter/空格手动整理，执行中禁止重复，完成后冷却 10 秒。显示系统实际前后占用，不能保证降幅或提速，可能短暂变慢或回升。
整理清除图片缓存并尝试回收普通后台应用工作集；跳过前台、系统、提权及无权限进程，不关闭应用，不操作显存，不需要管理员权限。

0.8.0-rc.11 截图窗口识别
截图时不再禁用整个原生窗口，保留窗口检测及边界查询；分别拦截点击、键盘和窗口移动，截图结束后恢复。

0.8.0-rc.10 截图交互与内存反馈
Snipaste 默认快捷键及受支持的系统截图触发时，展开面板保留画面但暂停点击和置顶，截图结束后恢复。
内存整理取消读秒和额外冷却：圆环先归零，完成后回到最新实测占用，动画结束可再次点击；数字保持真实，不代表内存曾降至 0%。


0.8.0-rc.12 桌面自动显示
默认开启：桌面无遮挡时展开，其他窗口遮挡时收起；移开、关闭或最小化后恢复，不抢焦点。
侧边入口或快捷键可临时展开在应用上方；图钉开启后保持展开。手动收起后不会立即弹回，切换到其他应用后返回桌面或主动唤出可恢复。
设置中可关闭“桌面自动展开，遮挡时收起”。截图、菜单、对话框、拖放及内存整理期间暂停自动切换。
